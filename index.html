Dulunya saya adalah siswa jurusan Rekayasa Perangkat Lunak dan Game di SMK 10 Semarang dengan passion yang kuat di bidang web development dan teknologi informasi.

Saya beberapa kali menghandle project berbasis IoT menggunakan ESP32 dan beberapa sensor lainya. Salah satu project yang pernah saya kerjakan adalah sistem monitoring hidroponik yang dapat mengirimkan data sensor ke website secara realtime.

Saat ini saya juga sedang mengembangkan project monitoring mini panel surya. Dari project tersebut, saya sekaligus mempelajari hubungan antara IoT, pemrograman, dan sistem energi yg memiliki hubungan pada prodi saya di POLINES.
